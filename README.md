1. Deskripsi Singkat Mengenai Repository
Repository adalah tempat penyimpanan proyek yang berisi file, kode program, serta riwayat perubahan yang dikelola menggunakan Git. Repository dapat digunakan secara lokal di komputer maupun secara online melalui GitHub.

2. Tujuan atau Kegunaan Repository
Repository memiliki beberapa tujuan dan kegunaan, yaitu:
- Menyimpan proyek: Menyimpan file dan kode program dalam satu tempat.
- Melacak perubahan: Mencatat setiap perubahan yang dilakukan pada file.
- Mengelola versi: Memungkinkan pengguna melihat atau kembali ke versi sebelumnya.
- Kolaborasi: Memudahkan beberapa pengguna bekerja bersama dalam satu proyek.
- Backup proyek: Menyimpan salinan proyek secara online melalui GitHub.

1. Rangkuman Materi
Materi Git & GitHub membahas penggunaan AI melalui Prompt Engineering serta pengelolaan proyek menggunakan Git dan GitHub. Git digunakan untuk mencatat dan mengelola perubahan file, sedangkan GitHub digunakan untuk menyimpan repository secara online dan mendukung kolaborasi. Materi juga membahas Git Workflow, perintah dasar Git, Git Setup, SSH Key, serta proses pengembangan aplikasi menggunakan AI dan GitHub.

2. Poin-Poin Mater
- Prompt Engineering adalah cara membuat instruksi AI agar menghasilkan jawaban yang sesuai.
- Git adalah sistem untuk mencatat dan mengelola perubahan file.
- GitHub adalah platform untuk menyimpan repository secara online.
- Git memiliki tiga bagian utama, yaitu Working Directory, Staging Area, dan Repository.
- Git memiliki perintah dasar seperti `git add`, `git commit`, `git push`, dan `git pull`.
- SSH Key digunakan untuk membantu menghubungkan komputer dengan GitHub.
- AI dapat membantu membuat aplikasi, sedangkan Git dan GitHub digunakan untuk mengelola perubahan aplikasi.

3. Pengetahuan Baru yang Diketahui
- Mengetahui perbedaan Git dan GitHub.
- Mengetahui cara menyimpan dan melacak perubahan file.
- Mengetahui perintah dasar Git.
- Mengetahui cara menghubungkan komputer dengan GitHub menggunakan SSH Key.
- Mengetahui bahwa GitHub dapat digunakan untuk menyimpan dan mengembangkan proyek bersama.

Git dan GitHub merupakan tools penting dalam pengembangan aplikasi karena membantu menyimpan, mengelola, dan melacak perubahan proyek.
